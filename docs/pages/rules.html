Rules

Every "no" has a name and a fix.

When bench refuses a line it prints the rule under the fault, and a refused step's MANIFEST carries rule=<id>. Each id below is stable — link to it as /rules/#<id>. Generated from supervisor/refusal.c; the same table is bench rules on your machine and /api/rules.json here.

FAULT line 2: ring: intern writes hold/ or proposed/ only, not main/x
  rule=write-ring fix: write under hold/ or proposed/; main/ is Ring 0
parse
the line dies at birth: the whole script is refused before any frame; no session.
run
the step was framed and refused: snapped with rule= in its evidence, then the run stops.
gate
the frame never ran (kill, disarm, helper lost): no step, no snap.

Playground

Write the intern's lines. See what bench would do — before you run it.

This is a mirror of the parser in supervisor/main.c and the foundation's slot gates, checked on every push against the ROM truth table (make site-check). It runs in your browser; nothing is sent anywhere. The binary stays the authority: a tool that is missing from tools/, a quota or a clock is only known at run time.

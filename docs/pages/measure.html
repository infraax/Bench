Reading it

  • The frame clock is not the bottleneck. T_frame is 200 ms; the worst steady frame measured (1000 unchanged files in hold/) is about 42 ms.
  • Python boot is the unit of cost. An EXEC is ~32 ms of worker time, of which the jail is about 1 ms.
  • Parallel means worlds. bench fork makes a new world in ~5.5 ms; four worlds run 3.6× faster side by side than one after another.

One machine, one day. Noise between runs is real (the empty frame ranged 0.6–2.7 ms across two worlds). Re-measure before quoting.

Architecture

Custody, not the loop.

Most agent tools are a loop: prompt → model → tool call → observe → repeat. They own the model and the context. Bench is the layer under a loop — the custody of the world the loop works on. It owns the clock, the gate, the write rings and the evidence. It trusts nothing the intern wrote until the owner crowns it.

How the layers stack

Five verbs — what each may touch

No sixth. A browser, a compiler or a judge is a program in tools/ or a device in a slot. Pick a verb:

READ

READ fs <path>

May touch

  • any regular file inside the world, through the fs slot
  • up to 4096 bytes; the bytes land in out-n, pinned by sha256

Must not

  • leave the world: no leading /, no .., no symlink followed
  • read a fifo, socket or device (it would hang the frame clock)
  • use a pulled slot: fb, judge, radio

rules: path-escape · fs-path · fs-cap · slot-pulled · read-payload

WRITE

WRITE fs <path> <one line>

May touch

  • hold/ (quarantine) and proposed/ (drafts)
  • one line per step, written atomically (temp + rename)
  • within the session's hold quota: 64 KiB and 256 entries of growth

Must not

  • write Ring 0: main/, tests/rom/, tools/, sessions/
  • mint the owner's token
  • follow a planted symlink out of the world

rules: write-ring · path-escape · fs-cap · hold-bytes · hold-files

EXEC

EXEC tools/<name>.py <args>

May touch

  • run a crowned program in tools/, with up to 16 relative args
  • as a worker that sees only the world; it writes only hold/, proposed/, tests/proposed/
  • for at most T_tool (5 s); 4096 bytes of output count

Must not

  • run anything outside tools/*.py — drafts wait for the crown
  • reach the network, mount, trace, or open io_uring (the worker is killed)
  • read outside the world: /etc, $HOME, /proc are not in its view

rules: exec-prog · exec-arg · exec-argc · sandbox · t-tool · tty-cap · out-ceil · worker-setup

TEST

TEST PURE|SCALAR tests/rom/<test>.py

May touch

  • run a crowned ROM test (Ring 0 muscle) in a worker
  • scratch in a private /tmp that vanishes with the worker

Must not

  • run a draft: only tests/rom/, whose hash is baked at build
  • move main/, ROM, prior snapshots or the token — the view refuses it, and the frame hashes before and after; anything moved disarms the run
  • use JUDGE or VISUAL: those slots are pulled

rules: test-path · test-kind · test-shape · test-moved · judge-pulled · visual-pulled

WAIT

WAIT <ms>

May touch

  • time only, up to T_tool (5000 ms); the evidence records what it slept
  • it is a step: framed, counted against N, snapshotted

Must not

  • wait on I/O or a gate — the spec's wider wait is not in this tree
  • outlive a KILL: the owner's stop ends the sleep

rules: wait-shape · t-tool · kill

Compare

Bench is not the same sport.

"Agent harness" means four different things. A loop runs the model; custody decides what a worker may touch and records what happened; an eval layer scores tasks; a meta-harness governs other harnesses. Bench is custody, with an eval layer's discipline about evidence. It does not solve benchmark tasks and makes no benchmark claims — a loop on top of it would.

What the custody layer adds

Every step is evidence

Sealed, content-hashed snapshot after each step; verify before restore or fork.

A closed action set

Five verbs instead of an open shell — the class of bug where an allowlisted command smuggles a second one has no path.

The key stays with the owner

The token is re-checked before every frame; tests cannot move main/, ROM, the token or prior snaps.

What it leaves to others

A model, context management, a policy list with an ASK tier, network access for workers, replay. Those belong to the loop on top — or to later sprints.

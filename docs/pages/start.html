Start

Linux, a compiler, Python — then one command.

  1. Check the machine

    Linux only (seccomp, landlock ≥ 5.13, mount and user namespaces). A C11 compiler, make, Python 3.10+ (stdlib only), git.

    sudo apt-get install -y build-essential python3 git
git clone https://github.com/infraax/Bench bench && cd bench
make env            # machine card; exits 2 with the install line if something is missing

  2. Run the full gate into the ledger

    make ledger-test    # make test, logged to ledger/<stamp>-<sha>/; prints only a summary

    It prints a short summary — exit code, ROM and harness counts — and the path to the full log. Paste the summary, not the log. make test-rom is the smaller gate (bus + ROM, no worker children) that hosted CI runs; it never replaces the ledger.

  3. Arm a world and run five verbs

    make
: > sessions/OWNER_TOKEN      # arm: yours, a regular file; rm it to disarm
echo hello > main/hello.txt
printf 'READ fs main/hello.txt\nWRITE fs hold/out.txt hi\nEXEC tools/hash.py hold/out.txt\n' > touch.ops
./supervisor/bench run touch.ops
./supervisor/bench status --line
./supervisor/bench verify

    The token is re-checked before every frame, by bench and by the helper. Removing or touching it stops the next step. The intern cannot create it.

  4. Read the lamps

    LampLit means
    MAINa crowned change reached main/ — dark in this tree
    HOLDwork sits in quarantine, hold/
    BLINDframebuffer and radio both pulled — always, in foundation

    MAIN and HOLD are never lit together.

Owner commands

CommandDoes
bench run <script>frame each line; snapshot after each step
bench status [--line]the board: session, lamps, snap, n/N
bench killstop the running session now; the cut step is snapped
bench verify [snap]re-hash stored snapshots against board=
bench restore <snap>load a verified snapshot as a new session
bench fork <snap> <dir>a new, unarmed world from a verified snapshot
bench rulesevery refusal rule and its one-line fix

Exit codes

CodeMeaning
0ok
1fault — a step was refused or failed; read the rule= line
2usage
3killed
4ROM changed since the build — rebuild with make
5not armed, or disarmed mid-run
6helper missing, silent, lost or wrong version
7world busy — another run holds the lock
Agents: run make env && make ledger-test before inventing work, and report the summary. Five verbs only; spec/ meaning is frozen; never put tokens or sessions/ contents in the ledger, a commit, or a chat.
